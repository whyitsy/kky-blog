# 前端 UI 层与主题系统设计（v3）

> 状态：实施中。本文件是 UI 层重构的**唯一契约来源**：目录边界、Token 契约、主题插件接口、
> 页面模型（Page Model）接口、主题切换机制都以此为准。实现细节以 `Blog.FrontEnd/src/ui/` 为准。
>
> 取代 `Blog.FrontEnd/参考设计规范/`（图片与 tokens 副本已删除，设计意图吸收进本文件与
> `src/ui/themes/aurora/DESIGN.md`）。

## 1. 目标

1. **UI 与业务分层**：业务/数据留在 `src/api`、`src/stores`、`src/views`；**所有视觉设计**
   进入独立的 `src/ui/` 层。页面视图退化为「数据控制器」，不再直接写视觉模板。
2. **主题插件化**：主题 = 一组 Token（颜色/字体/尺寸）+ 一个页面外壳（Shell）+ 若干页面组件。
   **切换主题不只是换色，是换布局**：导航位置、页面结构、列表/时间轴/专栏形态都由主题决定。
3. **收拢散落样式**：全站只保留一个基础样式层（reset / token 契约 / 通用组件类），
   禁止在页面里重复定义按钮、输入框、面板、徽章、横幅等基础视觉。
4. **删除参考设计规范**：`参考设计规范/` 里的图片、重复 tokens、SCSS 预置全部删除；
   其设计信息进入本文档与 aurora 主题的设计说明。
5. 兼容性不重要：允许破坏性重构；唯一的硬约束是 `vue-tsc -b && vite build`、`npm test`
   通过，以及现有功能行为不变。

### 边界规则

- `src/ui/**` 之外**不允许**出现视觉设计（颜色字面量、阴影、圆角、字体排印、按钮/输入框外观）。
- 后台（`/admin`）与作者区（`/me`）使用 **console UI**：共用 foundation primitives 与 Token，
  但布局固定、不参与主题切换（主题切换会改变其配色，因为 Token 全局生效）。
- 页面专属的「布局坐标」（grid 列数、间距）允许留在组件的 scoped style 中，但颜色、字体、
  圆角、阴影、基础控件外观必须来自 foundation。
- 公开站页面（可主题化）：`home / post-list / post-detail / archive / taxonomy /
  collection-list / collection-detail / not-found`。

## 3. Token 契约

Token 是主题之间唯一共享的视觉词汇。主题必须提供下表全部 Token；foundation 只消费 Token。

| 组 | Token | 说明 |
|---|---|---|
| 背景 | `--bg-canvas` `--bg-surface` `--bg-raised` `--bg-sunken` `--bg-invert` `--bg-overlay` | 页面/卡片/抬起/下沉/反色/遮罩 |
| 文字 | `--text-strong` `--text-default` `--text-muted` `--text-subtle` `--text-disabled` `--text-invert` | |
| 品牌 | `--brand-400/500/600` `--sub-400/500/600` `--accent-500` | 主/副/强调 |
| 渐变 | `--gradient-start` `--gradient-mid` `--gradient-end` | 极光渐变；主题可退化为单色 |
| 边框 | `--border-subtle` `--border-default` `--border-strong` | |
| 状态 | `--status-success` `--status-warning` `--status-danger` `--status-info` | 禁止再用硬编码 #e35151 等 |
| 字体 | `--font-sans` `--font-serif` `--font-mono` | |
| 字号 | `--text-display/-h1/-h2/-h3/-body/-body-sm/-caption` | font shorthand |
| 圆角 | `--radius-xs/sm/md/lg/xl/2xl` | 主题可整体调圆（如 paper 用 0） |
| 间距 | `--space-1..24` | |
| 尺寸 | `--size-prose` `--size-container` `--size-container-wide` `--size-sidebar` `--nav-height` | |
| 效果 | `--shadow-sm/md/lg` `--glow-cyan/purple/pink` `--glass-bg` `--glass-blur` | |
| 背景装饰 | `--page-bg-image` | 可选：主题提供的整页多层渐变/纹理，body 以 fixed 绘制；默认 none |
| 动效 | `--transition-fast/normal` | |
| 层级 | `--z-nav` `--z-overlay` `--z-modal` `--z-toast` | |

- 兜底值写在 `foundation/tokens.css` 的 `:root`（= aurora dark），主题值写在
  `[data-ui-theme='<id>'][data-color-mode='<mode>']` 选择器下。
- 主题可增加**私有** Token（如 `--aurora-hero-mask`），但 foundation 不得依赖私有 Token。

## 4. 主题插件接口

```ts
// src/ui/runtime/types.ts
export interface ThemePlugin {
  id: string
  name: string
  description: string
  /** 继承另一个主题：未覆盖的页面/外壳回退到父主题（内置主题使用，插件可选） */
  extends?: string
  /** 主题提供的配色模式；id 自定义（dark/light/ink/dusk…） */
  modes: ThemeMode[]
  defaultMode: string
  /** 主题切换器里的色板预览 */
  preview: { background: string; surface: string; text: string; primary: string; accent: string }
  /** 运行时注入的主题 CSS（外部插件用；内置主题走构建期 css import） */
  css?: string
  /** 页面外壳：默认插槽 = 当前路由页面。导航/页脚/搜索弹窗由 Shell 自行组合 */
  shell: Component
  /** 可主题化页面；未实现的页面回退到 extends 链 */
  pages: Partial<Record<PageId, Component>>
}
```

- `registerTheme(plugin)`（`runtime/registry.ts`）：内置与外部插件走同一个注册入口。
- 解析顺序：主题自身 → `extends` 链 → 无（页面为 `null` 时视图渲染兜底空态）。
- 内置主题在 `themes/index.ts` 静态注册（切换零加载）；外部插件可异步注册（插件接口不承诺 HMR）。
- 配色模式数量不限；切换器按主题动态渲染模式按钮。

## 5. 页面模型（Page Model）契约

视图（`src/views/*.vue`）= **数据控制器**：拉数据、做归一化、提供回调，然后：

```vue
<component :is="page" v-if="page" :model="model" />
```

主题页面（`ui/themes/*/pages/*.vue`）= **纯展示**：`defineProps<{ model: XxxPageModel }>()`。
所有页面模型定义在 `ui/contracts/pages.ts`：

| PageId | Model | 关键字段 |
|---|---|---|
| `home` | `HomePageModel` | `result / loading / goPage / tags（侧栏热门标签） / collections（侧栏专栏推荐）` |
| `post-list` | `PostListPageModel` | `result / loading / title / subtitle / goPage` |
| `post-detail` | `PostDetailPageModel` | `post / loading / notFound / loadFailed / toc / activeHeading / readProgress / renderedContent / readMinutes / publishedLabel / retry / scrollToHeading` |
| `archive` | `ArchivePageModel` | `total / loading / years: { year, months: { month, items: { id,title,dateLabel,publishedAt }[] }[] }[]` |
| `taxonomy` | `TaxonomyPageModel` | `kind('tag'|'category') / eyebrow / title / subtitle / items:{id,name,count}[] / loading / onSelect` |
| `collection-list` | `CollectionListPageModel` | `collections / loading` |
| `collection-detail` | `CollectionDetailPageModel` | `detail / loading / notFound / loadFailed / retry` |
| `not-found` | `NotFoundPageModel` | `attemptedPath / goHome / goBack` |

主题页面可以自由使用：`RouterLink`、`useSiteStore()`（站点配置/社交/统计）、
`@/ui` 导出的基础组件、foundation 类名。数据侧（API 调用、错误分类）只允许出现在视图层。

## 6. 主题切换

- 状态：`useThemeStore()`，持久化到 `localStorage`：`blog-ui-theme` / `blog-ui-mode`。
- DOM 契约：`<html data-ui-theme="aurora" data-color-mode="dark">`。
- **防首屏闪烁**：`index.html` 内联脚本在样式/渲染前读取 localStorage 并写入两个 data 属性；
  默认值由 `VITE_DEFAULT_THEME` / `VITE_DEFAULT_COLOR_MODE` 构建期注入（见 `Blog.FrontEnd/.env`）。
- 切换器：`ui/components/ThemeSwitcher.vue`，浮动按钮 → 面板（主题卡片 + 配色分段按钮）。
  公开站 `DefaultLayout`、`AdminLayout`、`AuthorLayout` 都挂载（后台只换配色、不换布局）。
- 系统偏好「跟随系统」不保留：模式由用户显式选择（默认由环境变量决定），避免首屏闪烁机制复杂化。
- **循环导入约束**：`ui/index.ts` 会静态 import 所有内置主题 → 主题包内的组件
  **不要** import `@/ui` barrel，改用具体模块（`@/ui/components/SiteLogo.vue`、
  `@/ui/runtime/store`、`@/ui/contracts/pages` 等）；视图/布局/后台才用 `@/ui`。

## 7. CSS 分层与命名

| 层 | 位置 | 说明 |
|---|---|---|
| reset/base | `foundation/reset.css` | 标签选择器、滚动条、动效降级、`.fade` 过渡 |
| tokens | `foundation/tokens.css` + 各主题 tokens.css | 只有自定义属性 |
| primitives | `foundation/primitives.css` | 通用类：`.btn*` `.input` `.field` `.label` `.panel*` `.badge*` `.banner*` `.table*` `.toolbar*` `.pager*` `.empty` `.hint` `.card` `.glass` `.gradient-text` `.tag-badge` `.category-badge` `.shimmer/.sk-*` `.container` `.page-header/.eyebrow/.page-title/.page-sub` `.link*` `.switch` `.avatar` 等 |
| theme | `themes/<id>/theme.css` + 组件 scoped style | 主题专属装饰与页面布局 |
| console | 后台组件 scoped style | 只放布局，视觉复用 primitives |

- 新 primitives 只允许加在 `foundation/primitives.css`，禁止在业务组件里复制。
- 状态色一律用 `--status-*`；透明叠加一律 `color-mix(in srgb, var(--token) N%, transparent)`。

### 已知边界

- 后台/作者区/登录页**不参与布局切换**，只有配色跟随主题 Token（刻意如此：管理界面布局求稳定）。
- 登录页是独立布局，没有主题切换器（需要先在公开站/后台切换）。
- 内置主题 CSS 全部构建期打包（切换零加载）；外部插件用 `plugin.css` 运行时注入，
  首屏不保证无闪烁（README 已说明）。
- 主题选择持久化在浏览器 localStorage，不是站点级全局配置；站点默认主题通过构建期
  `VITE_DEFAULT_THEME` / `VITE_DEFAULT_COLOR_MODE` 指定。
